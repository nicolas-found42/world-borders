# Publish bounded reference coverage while preserving historical gaps

The owner chose a partial Canada 1949 legal-affiliation reference and authorized bounded curator review rather than blocking all delivery on complete 1776 or North America geometry. Approval is tied to the exact reviewed source hash and scope; a government source, favorable model judgment, or event date cannot promote it to independently verified boundaries or effective control. Unsupported regions and 1776 remain explicit gaps, so later contributors cannot silently complete them with neighboring snapshots.
